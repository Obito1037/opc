# 映身 v0.2 · 验收记录

日期：2026-10-21（北京时间）。本文记录照片专项、3D、应用整合和服务实测。v0.1 的截图与报告保留为历史；以下结果来自 v0.2 本轮运行。

测试使用本机 Edge 无头浏览器、独立 Vite 源码服务。主要输入是明确标注为 AI 生成的 studio-model-v2.png，另外使用旧 CC0 走秀样片和无人物纯色图。测试脚本保存在 test-results/photo-v2/verify.cjs，最终记录是 [quality-report.json](../test-results/photo-v2/quality-report.json)。

| 检查 | 实际结果 |
| --- | --- |
| 白 T 样片识别 | 33 个身体点、478 个面部点，衣物语义分割有效，recolorAvailable 为 true |
| 真实面料调色 | 原衣褶皱、袖口、下摆和明暗可见；75,978 个像素的颜色变化超过测试阈值 |
| 完整画面 | 1,310,720 个像素均保持不透明，没有因人物抠图出现缺口 |
| 非目标区域 | 衣物遮罩外改动为 0；测试的脸颈上方区域及髋部以下裤子区域改动为 0；该指标不代表所有真人皮肤都已分割验证 |
| 暂停与动态 | 暂停后连续画面一致；恢复后运镜造成画面变化，明确不是生成肢体动作 |

| 无人物输入 | 身体、人脸与改色均不可用，没有虚构识别成功 |
| 页面运行 | 专项测试没有页面运行异常 |

## 已知边界

- 本地照片改色不改变衣服款式，不把商品图片贴合到真人身上。复杂印花、强光、遮挡及相近色背景可能触发保留原样；本轮真人样本覆盖仍少。
- 默认清晰样片为 AI 生成，只是演示输入。旧 CC0 走秀图负责复杂输入回归，两者都不能代替规模化真实用户测试。
- 视频模式的动作来自用户输入，只做脸部效果跟踪；不提供照片生视频、视频换衣、真实物体遮挡重建或准确色号承诺。
- 3D 是独立人台和示例服装，尚无用户身材测量、真实尺码推荐或布料物理拟合。
- 真实商品上传、高保真 AI 换衣、商品库、购买流程、比赛最终展示材料仍未完成。当前改进不能等同于完整比赛成品。
- 跨浏览器、真实断网、长时间稳定性、更多光照/肤色/服装样本及真实用户可用性测试仍需继续。
