## 3D 调度与画质专项

完整口径见 [performance-avatar-v3.md](performance-avatar-v3.md)。本轮保留模型、服装、骨骼与动作设计，主要调整调度、画质设置、数学对象复用和背景配色。

- 暂停稳定时停止 RAF 和连续 WebGL 提交；拖动、缩放、修改搭配与恢复播放仍触发更新。
- `auto`、`balanced`、`quality` 分别对应自动适配、流畅优先、精细画质；实际 DPR 受设备限制，自动模式可在持续慢帧时降低分辨率。
- 短时对比各采 4 秒，固定实际画布 596 × 650、DPR 1，运行于共享开发机器的无头 Edge。暂停稳定期间 v0.2 绘制 552 帧，v0.3 为 0；旧版隐藏容器已不绘制，新版进一步停止空转调度。
- 活动样本旧版约 123.13、新版约 120.07 帧 / 秒，不能据此声称活动帧率提升。默认阴影分辨率也发生变化，所以不是等画质 GPU 基准。
- 独立行为测试在尺寸调整清屏问题修复后重跑，12 项通过，另有弹窗及专注模式恢复回归。统计的 CPU 提交时间不是 GPU 完成时间，没有开展耗电或真实手机压力测试。

## 照片与视频调度专项

完整口径见 [performance-vision-v3.md](performance-vision-v3.md)，证据目录为 `test-results/vision-v3/`。开发构建和隔离生产构建均用真实本地 MediaPipe 模型，浏览器运行时异常为 0；隔离生产目录不是正式 `dist/`。

| 专项 | 结果与范围 |
| --- | --- |
| 照片连续输入 | 1024 × 1280 AI 示例，同一调用中连续 60 次妆容输入：完整合成由 60 次减少到 1 次，提交段耗时 575.2 ms → 0.3 ms；不包含等待下一帧显示，不是整站加速倍数 |
| 强制捕获 | 20 次修改后立即 capture，含 PNG 编码的总耗时 542.9 ms → 300.3 ms；只代表该样本 |
| 调色质量保持 | 新缓存路径与旧调色公式逐像素最大差为 0；关闭妆饰时衣物区域外无改动；复杂印花仍保留原图、空白图无伪检测 |
| 真实 Worker 推理 | 隔离生产约 3 秒窗口总 31 次检测，模型推理在 Worker；主线程模型推理 0 ms，不代表界面所有工作都无阻塞 |
| 回退路径 | 强制 Worker 不可用仍可工作，限频主线程检测；同窗口 Worker / 回退的 16 ms 定时器最大观察间隔为 17.6 / 30.5 ms，频率不同，不是严格等条件 FPS 比较 |
| 生命周期与对比 | 分屏端点和中间位置、暂停稳定、恢复视频变化、三档输入尺寸与资源释放通过 |

动态输入是已标注的 AI 样片移动裁剪 WebM，仅验证连续处理；没有打开真实摄像头，没有测试实拍快速转头、遮挡或不同肤色。照片首次识别仍在主线程分阶段执行；Worker / OffscreenCanvas 兼容性和更多设备表现需继续验证。

## 保持的能力边界

- 照片模式仍只对可靠区域改原衣颜色；不改变真实版型，不迁移商品图案。复杂输入可能保留原样。
- 视频动作来自输入视频或摄像头，不是单张照片生成真人动作；当前没有视频换衣。
- 3D 为独立陈列人台，没有本人重建、尺码测量或真实布料拟合。
- 真实商品图上传与 AI 换新款尚未实现。AI 服务适配器默认关闭、未连接前端；历史官方演示测试额度不足，见 [服务实测](ai-provider-research-v2.md)。
- 没有声称真实断网、长时间稳定性、所有手机浏览器或广泛真人样本都已通过；当前仍是比赛交互原型。
