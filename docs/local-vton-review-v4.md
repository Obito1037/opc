# 本机 CatVTON 独立边界审查

2026-10-21。本记录审查 `server/local-vton.mjs`、`scripts/vton-v4/infer.py` 与同源 API 的接法。审查和协议测试没有加载真实权重，也没有与正在执行的 CPU 模型争抢推理资源。真实生成耗时及画质应以另外保存的实际输出和验收记录为准。

## 已落实的边界

- Node 仅执行服务器配置的 Python 和 runner，通过参数数组启动，关闭 shell 并隐藏窗口。用户请求只能传图片数据、支持的服装参数，不能提交命令、模型地址或系统路径。提交前使用 realpath、目录限制、大小及图片结构校验。
- 本地环境和模型文件准备完成仅代表 `configured`；本进程真正返回并校验结果后才设置 `verifiedGeneration`。API 还再次校验结果。缺失、超大、无效输出或子进程失败不能成为成功任务。
- 取消会终止该任务的 Python 子进程并清理部分输出。输出 stat 先于 readFile，限制 12 MiB；读取前后复查取消信号，避免取消后发布成功。
- CatVTON 公开运行预算 `maxDurationMs:1800000`。API 对活动 CatVTON 任务保留同等输入窗口，避免通用 15 分钟清理提前中断。结束、取消、崩溃恢复仍立即清理输入；其他 provider 与孤立文件维持原窗口。能力接口公开 `limits.activeSourceTtlMsByProvider`。这是上限，不是完成时间承诺。
- Python 分阶段加载分割、VAE、UNet、安全检查器，释放前阶段模型；CFG 条件与无条件前向分开执行以降低峰值批次内存。人物工作副本限制 1280 长边，商品限制 1600 长边。图片最初解码仍有临时内存开销；未将代码审查当作峰值内存实测。
- 生产启动参数没有 `--diagnostics`，因此不保存中间人物、商品、mask 或报告。显式诊断 CLI 的目录属于调用者主动保留的研究证据。保留原 Stable Diffusion 安全检查，输出必须通过后才能保存。
- 本机 provider 现在只公开 `garmentPhotoTypes:['flat-lay']`，模特商品图在启动子进程前拒绝。错误码与消息都由固定白名单重建，文件系统异常、自定义取消原因及 runner 原文不外显；已知错误码也不能携带任意原文。进度消息仅保留已知阶段或有界真实步数。
- 对照已取得的官方 CatVTON pipeline 源码，纵向 latent 拼接、零条件分支、CFG 代数及取前半结果的顺序一致。这只是源码层面检查，不等于数值等价或画质达标。

## 复现测试

`node --test tests/local-vton.test.mjs` 共 10 项：

1. 配置完成与结果验证分离；真实子进程协议执行及输出校验。
2. 越界输入在启动进程前拒绝；零退出却缺失输出仍失败。
3. 已运行任务取消后 Python PID 消失、busy 释放、部分输出删除；并发请求拒绝。
4. 子进程写出超过 12 MiB 的文件后拒绝、删除且不标记验证通过。
5. 预先取消不启动子进程；明确失败事件不能产生成功结果。
6. 虚拟时钟下本机活动任务第 16 分钟仍持有输入，第 31 分钟取消并删除输入，只保留任务元数据。
7. 能力仅公开平铺图，模特商品图在启动前拒绝。
8. 已知 / 未知 runner 错误码、文件系统异常、自定义取消原因与进度不能泄露绝对路径；真实步数保留。
9. 同源 HTTP 失败任务与 capabilities 均不输出 runner 路径。
10. 语义解析的 `PERSON_NOT_FOUND / MULTIPLE_PEOPLE / UNSUPPORTED_SOURCE_GARMENT / REGION_NOT_FOUND` 逐一返回固定中文提示，忽略 runner 携带的私有路径；不标记成功、不保留输出。

测试 Python 仅使用标准库。测试自建假模型清单及复制输入的模式均是显式、隔离的 **协议 fixture**，没有 AI 推理含义，也不是生产回退方式。测试临时目录完成后删除。2026-10-21 语义解析业务码补充后，独立本机套件 **10 / 10 通过，0 跳过**；保留实现者更新的 parser / viton 权重清单，没有加载真实模型。

## 审查时仍待真实证据的部分

CPU 运行耗时、峰值内存、纹理保留和手部遮挡不能由这些测试证明。语义分割与按人体比例选择区域的自动 mask 可能不适合复杂姿势和多层穿搭。当前默认计算已改为 FP32；实际 24 步画质与耗时须以真实输出记录为准。
